# Wildpark Eekholt: бенчмарк и бренд

## Бренд (из логотипа и Jahreskarten)

| Роль | Цвет | Откуда |
|---|---|---|
| Основной | `#C8C901` лаймово-оливковый | плашка логотипа |
| Текст / силуэт | `#0A0A0A` почти чёрный | орёл, wordmark |
| Карта «Erwachsene» | `#334A9A` синий | Jahreskarte |
| Карта «Familien» | `#BE2A0C` кирпично-красный | Jahreskarte |
| Карта «Großeltern» | `#A169A8` сиреневый | Jahreskarte |
| Карта «Kinder» | `#F07F1F` оранжевый | Jahreskarte |
| Kinder 2026 | голубой `~#1E8FD0` | Jahreskarte 2026 |

- Знак: силуэт орла, который выходит за край прямоугольной плашки. Это главный графический приём бренда: объект ломает рамку. Его можно использовать в вёрстке (фото и вырезки за пределами блоков).
- Шрифт wordmark: гуманистический гротеск с разрядкой капсом (WILDPARK / E E K H O L T). В печатных материалах есть курсив «NaturErlebnisse» и капитель «JAHRESKARTE».
- Слоган из печати: **NaturErlebnisse**, его стоит вернуть на сайт.
- Цвета Jahreskarten уже работают как система цветового кодирования по аудиториям. Используем их как вторичную палитру: тарифы, аудитории, категории событий.
- Фото: натуралистичные, крупные планы животных, без постановки.

## Конкуренты: что берём, чего избегаем

| | Schwarze Berge | Lüneburger Heide | Arche Warder | Tierpark Neumünster |
|---|---|---|---|---|
| Онлайн-билеты | да | да, кнопка в шапке | нет | нет |
| «Сегодня открыто» | нет | закреплённая полоса внизу | только «ganzjährig» | часы в шапке |
| События | текст + категории | «Vorführungen heute» с маркером «идёт сейчас» | карточки с датой | внешний календарь |
| Животные | плитки с фото | Tierlexikon | категории + A–Z | хайлайты |
| Слабые места | устаревшие блоки, дубли меню | 3 домена магазина, дубли | пустые alt, повторы CTA | H1 в самом низу, смешение языков |

**Берём (без новых функций, только подача существующего контента):**
1. Строка «Heute geöffnet · Einlass bis 16:00» из уже имеющихся часов работы (Lüneburger Heide, Neumünster).
2. Расписание кормлений и полётов на сегодня, с пометкой текущего события. Данные уже есть на сайте Eekholt.
3. Карточки событий с датой на первом плане и фильтр по месяцам (Arche Warder).
4. Плитки животных с фото, A–Z и группировка (Schwarze Berge, Arche Warder).
5. Навигация по аудиториям: Familien, Schulen & Gruppen, Best Ager. Такие страницы у Eekholt уже есть, их просто не видно.

**Избегаем:** слайдера в hero, дублирования меню и CTA, устаревших блоков на главной, смешения Du и Sie (у Eekholt «Sie», оставляем).

## Чем Eekholt может выиграть
- Уникальные темы, которых нет у конкурентов: Wolfsinformationszentrum SH (Wolfsmeile), Vogelpflegestation, Artenschutz (Seeadler, Fischotter, Eulen). Даём им отдельные выразительные блоки.
- Год без перерывов, много сезонных событий: главная живёт по сезонам за счёт контента, без слайдера.
- Цены честнее и проще, чем у конкурентов: показываем карточками, Familienkarte и Jahreskarte в цветах печатных карт.
